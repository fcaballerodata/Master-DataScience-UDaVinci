# ⛏️ Minería de Datos

**Trimestre 3 — Universidad DaVinci**
📅 Septiembre – Noviembre 2026 | 10 semanas | 10 Unidades Didácticas

---

## 📋 Descripción

Asignatura enfocada en el proceso de Minería de Datos (Data Mining) y su relación con el Aprendizaje Automático: desde el proceso KDD y las principales técnicas (RNA, árboles de decisión, reglas, redes bayesianas, algoritmos genéticos), hasta su aplicación en texto, web y marketing.
