## 📋 Descripción

Asignatura enfocada en los fundamentos del Machine Learning y las Redes Neuronales Artificiales (RNA): desde qué es el ML y dónde se aplica, hasta la construcción, entrenamiento e interpretación de resultados de una RNA.
